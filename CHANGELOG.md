# Changelog

## 0.1.0 — 2026-11-17

- Inicialización del proyecto Android Kotlin/Compose con API mínima 26 y Java 17.
- Modelos de dominio iniciales para perfiles, tareas, roles y estados.
- Cloud Functions iniciales para creación de familia, invitación y vinculación infantil, tareas y aprobación transaccional con ledger de puntos.
- Reglas Firestore denegando escrituras del cliente y accesos no familiares.
- Documentación de configuración, límites de Android y estado de verificación.
